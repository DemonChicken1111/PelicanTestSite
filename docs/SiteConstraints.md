# Project Brief: Corporate Marketing Website

**Prepared by:** Northshore Digital Consulting
**Audience:** Contract Web Developer
**Platform:** Pelican (Static Site Generator)

---

## 1. Project Overview

Northshore Digital Consulting is commissioning a lightweight, fast, and maintainable static website to serve as our public-facing marketing presence. The site should communicate credibility, technical competence, and approachability, while remaining easy to update via Markdown.

The website will initially be **informational only** (no user accounts, no backend), with the ability to expand later if needed.

---

## 2. Goals & Objectives

The primary goals of this website are to:

* Clearly explain **who we are** and **what we do**
* Establish **trust** with potential clients
* Provide a simple way for visitors to **contact us**
* Be **performant**, **accessible**, and **SEO-friendly**
* Be easy for non-developers to update using **Pelican**

---

## 3. Site Structure

### 3.1 Home (`index.html`)

**Purpose:** First impression and value proposition

**Content Sections:**

* Hero section with concise tagline
* Brief overview of services
* Short “Why Choose Us” section
* Clear **call-to-action** linking to Contact page

**Tone:** Professional, confident, approachable

---

### 3.2 About Us (`pages/about.md`)

**Purpose:** Build trust and credibility

**Content:**

* Company background and mission
* Consulting philosophy
* Brief overview of experience and industries served

---

### 3.3 Services (`pages/services.md`)

**Purpose:** Clearly explain offerings

**Content:**

* Core services list:

  * IT Consulting
  * Infrastructure & Networking
  * Systems Administration
  * Security & Risk Assessment
* Short description for each service
* Emphasis on **outcomes**, not buzzwords

---

### 3.4 Blog / Insights (`category/blog.html`)

**Purpose:** Demonstrate expertise and support SEO

**Content:**

* Short-form articles written in Markdown
* Chronological listing
* RSS feed enabled

**Example Topics:**

* Infrastructure best practices
* Security fundamentals
* Technology decision-making for small organizations

---

### 3.5 Contact (`pages/contact.md`)

**Purpose:** Convert visitors into leads

**Content:**

* Business email address
* Optional static-compatible contact form (e.g., Formspree)
* General business location (city/state only)

---

## 4. Visual & Design Guidelines

* Minimalist layout
* Neutral color palette (grays, blues, whites)
* Readable sans-serif typography
* Mobile-responsive design
* Minimal JavaScript usage

---

## 5. Technical Requirements

* Built using **Pelican**
* Content authored in **Markdown**
* Clean, readable URL structure
* SEO-friendly metadata
* RSS feed for blog content
* Simple, maintainable Jinja templates
* Compatible with Git-based deployment
